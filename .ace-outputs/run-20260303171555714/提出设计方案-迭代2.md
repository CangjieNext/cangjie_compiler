**新设计**：自动检测 + Git Clone

```cmake
# 自动检测 third_party/mimalloc 目录
if(NOT EXISTS ${MIMALLOC_SOURCE_DIR}/CMakeLists.txt)
    # 目录不存在时自动克隆
    execute_process(
        COMMAND ${GIT_EXECUTABLE} clone --depth 1 --branch v2.1.7
                https://gitcode.com/GitHub_Trending/mi/mimalloc.git
                ${MIMALLOC_SOURCE_DIR}
    )
endif()
```

- 使用 GitCode 镜像地址：`https://gitcode.com/GitHub_Trending/mi/mimalloc.git`
- 首次构建自动克隆，后续构建复用本地源码
- 完全支持离线构建场景
