## 三、新发现优化建议

### OPT-NEW-1（P3）：共享头文件抽取

**文件**：所有入口点文件

**问题描述**：
当前 `main.cpp`、`main-macrosrv.cpp`、`main-chir-dis.cpp` 三个文件都包含重复的 mimalloc 初始化代码：
- mimalloc 头文件包含
- Windows 平台的 `MimallocInit` 静态对象
- `mi_option_set` 调用

**当前代码重复示例**：

`main.cpp:27-42`:
```cpp
#ifdef CANGJIE_USE_MIMALLOC
#include <mimalloc.h>
#ifdef _WIN32
#include <mimalloc-new-delete.h>
struct MimallocInit {
    MimallocInit() { mi_process_init(); }
};
static MimallocInit g_mimallocInit;
#endif
#endif
```

`main-macrosrv.cpp:7-18`:
```cpp
#ifdef CANGJIE_USE_MIMALLOC
#include <mimalloc.h>
#ifdef _WIN32
#include <mimalloc-new-delete.h>
struct MimallocInit {
    MimallocInit() { mi_process_init(); }
};
static MimallocInit g_mimallocInit;
#endif
#endif
```

`main-chir-dis.cpp:13-24`:
```cpp
#ifdef CANGJIE_USE_MIMALLOC
#include <mimalloc.h>
#ifdef _WIN32
#include <mimalloc-new-delete.h>
struct MimallocInit {
    MimallocInit() { mi_process_init(); }
};
static MimallocInit g_mimallocInit;
#endif
#endif
```

**修复建议**：
创建共享头文件 `include/cangjie/Utils/MimallocInit.h`：

```cpp
// include/cangjie/Utils/MimallocInit.h
#ifndef CANGJIE_UTILS_MIMALLOC_INIT_H
#define CANGJIE_UTILS_MIMALLOC_INIT_H

#ifdef CANGJIE_USE_MIMALLOC
#include <mimalloc.h>

#ifdef _WIN32
#include <mimalloc-new-delete.h>

// Ensure mimalloc is initialized before any global constructors
struct MimallocInit {
    MimallocInit() { mi_process_init(); }
};
static MimallocInit g_mimallocInit;
#endif

// Initialize mimalloc options at the very beginning
// This must be done before any memory allocation
inline void InitMimallocOptions()
{
    mi_option_set(mi_option_reset_delay, 0);
    mi_option_set(mi_option_eager_commit_delay, 0);
}

// Verify mimalloc is properly initialized
inline void CheckMimallocInit()
{
    void* test = mi_malloc(16);
    if (!test) {
        fprintf(stderr,
            "Warning: mimalloc initialization failed. "
            "This may cause allocation failures.\n");
    } else {
        mi_free(test);
    }
}

#endif // CANGJIE_USE_MIMALLOC

#endif // CANGJIE_UTILS_MIMALLOC_INIT_H
```

各入口点只需包含头文件并调用：
```cpp
#include "cangjie/Utils/MimallocInit.h"

int main(...) {
#ifdef CANGJIE_USE_MIMALLOC
    InitMimallocOptions();
    CheckMimallocInit();
#endif
    // ... rest of code
}
```

**严重程度**：P3（优化项）
**优先级**：低（仅影响代码维护性，不影响功能正确性）

### OPT-NEW-2（P3）：CheckMimallocInit 缺失

**文件**：`main-macrosrv.cpp`、`main-chir-dis.cpp`

**问题描述**：

`main.cpp:105-110`（完整实现）:
