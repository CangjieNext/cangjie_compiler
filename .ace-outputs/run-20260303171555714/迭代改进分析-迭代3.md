# 迭代改进分析 - 迭代3

## 本轮发现的问题

### 问题1：CMake 混用签名错误
CMake 不允许对同一目标混用关键字签名和纯签名。原始代码在 cjc、LSPMacroServer、chir-dis 上混用了两种签名。

**修复方案**：将 mimalloc 链接放在所有其他 `target_link_libraries` 调用之后，并使用纯签名（无 PRIVATE 关键字）。

### 问题2：CangjieMimalloc.cmake 语法错误
CMake 文件开头的 C 风格注释 `/**` 导致解析错误。

**修复方案**：移除所有 C 风格注释，只保留 CMake 注释。
