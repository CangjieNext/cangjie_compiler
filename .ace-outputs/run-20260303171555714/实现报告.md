## 二、CMake 模块实现

### 2.1 mimalloc 源码获取

采用自动检测 + Git Clone 策略：

```cmake
# 自动检测 third_party/mimalloc 目录
if(NOT EXISTS ${MIMALLOC_SOURCE_DIR}/CMakeLists.txt)
    message(STATUS "mimalloc source not found, cloning from ${MIMALLOC_GIT_REPO}...")
    find_package(Git REQUIRED)
    execute_process(
        COMMAND ${GIT_EXECUTABLE} clone --depth 1 --branch ${MIMALLOC_GIT_TAG}
                ${MIMALLOC_GIT_REPO} ${MIMALLOC_SOURCE_DIR}
        ...
    )
endif()
```

### 2.2 Sanitizer 互斥逻辑

自动检测并禁用 Sanitizer 构建下的 mimalloc：

```cmake
if(CANGJIE_SANITIZER_SUPPORT_ENABLED OR CANGJIE_ENABLE_ASAN OR ...)
    message(WARNING "CANGJIE_USE_MIMALLOC is disabled due to ${MIMALLOC_CONFLICT_REASON}.")
    set(CANGJIE_USE_MIMALLOC OFF)
endif()
```

### 2.3 平台特定配置

- **Linux/macOS**：启用全局符号覆盖（`MI_OVERRIDE=ON`）
- **Windows**：仅替换 new/delete（`MI_OVERRIDE=OFF`）

## 四、内存归还策略实现

### 4.1 DeleteInstance 函数

```cpp
bool DeleteInstance(DefaultCompilerInstance* instance)
{
    delete instance;
#if defined(__linux__) || defined(__APPLE__)
#ifndef __ohos__
#ifdef CANGJIE_USE_MIMALLOC
    mi_collect(true);
    mi_heap_collect(mi_heap_get_default(), true);
#else
    (void)malloc_trim(0);
#endif
#endif
#endif
    return true;
}
```

### 4.2 同步析构策略

```cpp
#ifdef CANGJIE_USE_MIMALLOC
    DeleteInstance(instance);  // 同步调用，避免竞态
    bool res = InvokeCompileToolchain();
#else
    std::future<bool> future = std::async(DeleteInstance, instance);
    bool res = InvokeCompileToolchain();
    future.get();
#endif
```
