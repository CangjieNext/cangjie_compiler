# 缺陷修复建议汇总

本文档是《威胁建模与缺陷分析报告.md》的快速参考版本，按优先级列出所有缺陷及修复建议。

## P0 级缺陷（阻塞发布）

### BUG-01：mi_collect 与 malloc_trim 语义不等价

**修复方案**（三选一）：

```cpp
// 方案 1：增强 mi_collect 调用（推荐）
bool DeleteInstance(DefaultCompilerInstance* instance)
{
    delete instance;
#if defined(__linux__) && !defined(__ohos__)
#ifdef CANGJIE_USE_MIMALLOC
    mi_collect(true);
    mi_option_set(mi_option_eager_commit_delay, 0);
    mi_option_set(mi_option_reset_delay, 0);
    mi_heap_collect(mi_heap_get_default(), true);
    std::this_thread::sleep_for(std::chrono::milliseconds(10));
#else
    (void)malloc_trim(0);
#endif
#endif
    return true;
}

// 方案 2：禁用异步 DeleteInstance（保守）
#ifdef CANGJIE_USE_MIMALLOC
    bool res = InvokeCompileToolchain();
    DeleteInstance(instance);  // 同步调用
#else
    std::future<bool> future = std::async(DeleteInstance, instance);
    bool res = InvokeCompileToolchain();
    future.get();
#endif

// 方案 3：使用 mi_heap_t 隔离堆（最佳，需重构）
class DefaultCompilerInstance {
    mi_heap_t* heap = mi_heap_new();
    ~DefaultCompilerInstance() {
        mi_heap_delete(heap);  // 自动归还
    }
};
```

**修复方案**：同 BUG-01 方案 2 或方案 3

## P1 级缺陷（合并前修复）

### BUG-03 & BUG-13：Sanitizer 互斥逻辑不完整

**修复方案**：

```cmake
# cmake/optional/CangjieMimalloc.cmake
set(MIMALLOC_CONFLICT_REASON "")

if(CANGJIE_SANITIZER_SUPPORT_ENABLED)
    set(MIMALLOC_CONFLICT_REASON "sanitizer support")
elseif(CANGJIE_ENABLE_ASAN)
    set(MIMALLOC_CONFLICT_REASON "compiler ASan")
elseif(CANGJIE_ENABLE_ASAN_COV)
    set(MIMALLOC_CONFLICT_REASON "ASan coverage")
elseif(CANGJIE_ENABLE_COMPILER_TSAN)
    set(MIMALLOC_CONFLICT_REASON "compiler TSan")
elseif(CANGJIE_ENABLE_HWASAN)
    set(MIMALLOC_CONFLICT_REASON "HWASan")
endif()

# 检查编译标志中的 LeakSanitizer
string(FIND "${CMAKE_CXX_FLAGS}" "-fsanitize=leak" LSAN_POS)
if(NOT LSAN_POS EQUAL -1)
    set(MIMALLOC_CONFLICT_REASON "LeakSanitizer")
endif()

if(MIMALLOC_CONFLICT_REASON)
    message(WARNING "CANGJIE_USE_MIMALLOC disabled: ${MIMALLOC_CONFLICT_REASON}")
    set(CANGJIE_USE_MIMALLOC OFF CACHE BOOL "" FORCE)
    return()
endif()
```

### BUG-08：ExternalProject 离线构建失败

**修复方案**：

```cmake
# cmake/optional/CangjieMimalloc.cmake
set(MIMALLOC_SOURCE_DIR ${CMAKE_SOURCE_DIR}/third_party/mimalloc)

if(NOT EXISTS ${MIMALLOC_SOURCE_DIR}/CMakeLists.txt)
    message(FATAL_ERROR
        "mimalloc source not found at ${MIMALLOC_SOURCE_DIR}.\n"
        "Please run: git submodule update --init third_party/mimalloc")
endif()

# 移除 ExternalProject 自动下载逻辑
add_subdirectory(${MIMALLOC_SOURCE_DIR} ${CMAKE_BINARY_DIR}/mimalloc EXCLUDE_FROM_ALL)
```

### OPT-06：缺少结构化统计输出

```cpp
#ifdef CANGJIE_USE_MIMALLOC
void PrintMimallocStats()
{
    if (getenv("CANGJIE_MIMALLOC_STATS")) {
        size_t peak_rss, current_rss, page_faults;
        mi_process_info(nullptr, nullptr, nullptr,
                        &current_rss, &peak_rss, nullptr, nullptr, &page_faults);
        fprintf(stderr,
            "{\"mimalloc_stats\": {"
            "\"peak_rss_mb\": %zu, "
            "\"current_rss_mb\": %zu, "
            "\"page_faults\": %zu"
            "}}\n",
            peak_rss / 1024 / 1024,
            current_rss / 1024 / 1024,
            page_faults);
    }
}
#endif
```
