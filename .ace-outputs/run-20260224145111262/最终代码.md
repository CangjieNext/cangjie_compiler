## 一、功能概述

在仓颉编译器中，AST（抽象语法树）在 CHIR lowering 完成后不再被后续阶段（CodeGen、结果保存）直接使用。本实现在 CHIR 阶段结束后释放 AST 内存，降低编译器峰值内存占用。

核心机制：
- **A-3 函数体粒度释放**：在 CHIR lowering 过程中，每翻译完一个函数/变量，立即释放其 AST 函数体/初始化器（~60-80% AST 内存）
- **RELEASE_AST 流水线阶段**：CHIR 完成后，通过 5 阶段清理释放剩余 AST 声明骨架和管理器
- **CodeGen 解耦**：通过 `PackageCodeGenInfo` 结构体将 CodeGen 与 `srcPkgs` 解耦
- **ADR-009 缓存前移**：增量编译缓存写入和结果保存在 AST 释放前执行
- **调试开关**：`--no-release-ast` 选项跳过释放，用于 ASan/内存分析

## 三、A-3 函数体粒度释放

在 `AST2CHIR::TranslateAllDecls()` 中，每翻译完一个 AST 节点，立即释放其代码块。只释放 `FuncBody::body`（代码块）和 `VarDeclAbstract::initializer`（初始化器），保留签名级成员（`paramLists`、`retType`），因为 `GlobalDeclAnalysis` 和 `AST2CHIRCheck` 仍需引用它们。

### 3.1 头文件声明


### 3.2 实现

```cpp
// src/CHIR/AST2CHIR/AST2CHIR.cpp

void AST2CHIR::ReleaseFuncBody(const AST::Decl& decl)
{
    if (decl.astKind != AST::ASTKind::FUNC_DECL) {
        return;
    }
    // const_cast is safe: we own the AST tree and are past the translation point for this decl.
    auto& funcDecl = const_cast<AST::FuncDecl&>(static_cast<const AST::FuncDecl&>(decl));
    if (funcDecl.funcBody != nullptr && funcDecl.funcBody->body != nullptr) {
        funcDecl.funcBody->body.reset();
    }
}

void AST2CHIR::ReleaseVarInitializer(AST::VarDeclAbstract& decl)
{
    if (decl.initializer != nullptr) {
        decl.initializer.reset();
    }
}

void AST2CHIR::ReleaseTranslatedNominalBodies(const AST::Package& /* pkg */)
{
    auto releaseMethodBodies = [this](const std::vector<Ptr<const AST::Decl>>& decls) {
        for (auto& decl : decls) {
            auto& memberDecls = decl->GetMemberDecls();
            for (auto& member : memberDecls) {
                ReleaseFuncBody(*member);
            }
        }
    };
    releaseMethodBodies(nominalDecls);
    releaseMethodBodies(genericNominalDecls);
}

void AST2CHIR::ReleaseTranslatedInitializers(const InitOrder& initOrder)
{
    for (auto& [file, decls] : initOrder) {
        for (auto& decl : decls) {
            if (auto* varDecl = DynamicCast<AST::VarDeclAbstract*>(
                    const_cast<AST::Decl*>(decl.get()))) {
                ReleaseVarInitializer(*varDecl);
            }
        }
    }
}

void AST2CHIR::ReleaseAllTranslatedFuncBodies()
{
    for (auto decl : globalAndMemberFuncs) {
        if (NeedTranslate(*decl)) {
            ReleaseFuncBody(*decl);
        }
    }
    for (auto decl : std::as_const(localConstFuncs.stableOrderValue)) {
        ReleaseFuncBody(*decl);
    }
}
```

### 3.3 集成到 TranslateAllDecls

```cpp
void AST2CHIR::TranslateAllDecls(const AST::Package& pkg, const InitOrder& initOrder)
{
    // step 1: translate nominal decls
    TranslateNominalDecls(pkg);
    ReleaseTranslatedNominalBodies(pkg);  // 批量释放方法体

    // step 2: translate global var initializers
    TranslateInitOfGlobalVars(pkg, initOrder);
    ReleaseTranslatedInitializers(initOrder);  // 批量释放初始化器

    // step 3: translate function bodies
    if (opts.GetJobs() > 1) {
        TranslateTopLevelDeclsInParallel();
        ReleaseAllTranslatedFuncBodies();  // 并行翻译后批量释放
    } else {
        for (auto decl : globalAndMemberFuncs) {
            // ... translate ...
            ReleaseFuncBody(*decl);  // 串行翻译后逐个释放
        }
        for (auto decl : std::as_const(localConstFuncs.stableOrderValue)) {
            // ... translate ...
            ReleaseFuncBody(*decl);
        }
    }
    for (auto decl : annoFactoryFuncs) {
        // ... translate ...
        ReleaseFuncBody(*decl.first);  // 注解工厂函数逐个释放
    }

    // step 4: set CompileTimeValue for lambda (operates on CHIR IR, unaffected by AST release)
    // ...
}
```

```cpp
    bool resultsSaved = false;
```

### 4.2 PerformASTRelease 实现

```cpp
// src/Frontend/CompilerInstance.cpp

void CompilerInstance::PrepareCodeGenInfo()
{
    if (!codeGenPkgInfos.empty()) {
        return;  // Idempotent guard.
    }
    for (auto& srcPkg : srcPkgs) {
        PackageCodeGenInfo info;
        info.fullPackageName = srcPkg->fullPackageName;
        info.isEmpty = srcPkg->IsEmpty();
        codeGenPkgInfos.push_back(std::move(info));
    }
}

bool CompilerInstance::PerformASTRelease()
{
    Utils::ProfileRecorder recorder("Main Stage", "Release AST");

    // Extract CodeGen metadata before potential release.
    PrepareCodeGenInfo();

    // Save results (e.g., CJO in CHIR output mode) before AST is freed.
    if (!resultsSaved) {
        if (!PerformResultsSaving()) {
            return false;
        }
        resultsSaved = true;
    }

    // Write incremental compilation cache before AST is freed (ADR-009).
    if (ShouldWriteCacheFile() && !cacheWritten) {
        UpdateCachedInfo();
        WriteCachedInfo();
        cacheWritten = true;
    }

    // Allow skipping AST release for debugging.
    if (invocation.globalOptions.noReleaseAST) {
        return true;
    }

    ReleaseASTMemory();
    return true;
}
```

### 4.3 ReleaseASTMemory 5 阶段清理

```cpp
void CompilerInstance::ReleaseASTMemory()
{
    if (astReleased) {
        return;
    }

    // Phase 1: Clear CHIR-layer AST references
    CHIR::ClearGlobalAnnotationInfo();

    // Phase 2: Clear CompilerInstance direct member AST references
#ifdef CANGJIE_CODEGEN_CJNATIVE_BACKEND
    astPkg2chirPkgMap.clear();
#endif
    currentPkg = nullptr;
    mangledName2DeclMap.clear();
    rawMangleName2DeclMap.clear();
    declsWithDuplicatedRawMangleName.clear();
    directExtends.clear();
    order.clear();
    chirInfo.ccTys.clear();
    pkgs.clear();

    // Phase 3: Release managers (destruction order matters)
    delete typeChecker;   typeChecker = nullptr;   // 3a
    delete typeManager;   typeManager = nullptr;   // 3b
    delete gim;           gim = nullptr;           // 3c
    delete testManager;   testManager = nullptr;   // 3d
    mangler.reset();                               // 3e
    importManager.ClearASTReferences();            // 3f
    if (packageManager) {
        packageManager->ClearASTReferences();      // 3g
    }

    // Phase 4: Release AST core data
    srcPkgs.clear();     // 4a: AST nodes
    pkgCtxMap.clear();   // 4b: ASTContext

    // Phase 5: Mark completion
    astReleased = true;
}
```

### 4.4 析构函数安全守卫

```cpp
CompilerInstance::~CompilerInstance()
{
    if (!astReleased) {
        // Normal destruction path — managers not yet freed.
        srcPkgs.clear();
        pkgCtxMap.clear();
        delete typeChecker;  typeChecker = nullptr;
        delete typeManager;  typeManager = nullptr;
        delete testManager;  testManager = nullptr;
        delete gim;          gim = nullptr;
    }
    // Always clean these regardless of AST release state.
    delete compileStrategy;  compileStrategy = nullptr;
    delete packageManager;   packageManager = nullptr;
}
```

### 4.5 缓存写入守卫

```cpp
bool CompilerInstance::UpdateAndWriteCachedInfoToDisk()
{
    // If cache was already written during PerformASTRelease, skip.
    if (cacheWritten) {
        return true;
    }
    if (!ShouldWriteCacheFile()) {
        return true;
    }
    UpdateCachedInfo();
    return WriteCachedInfo();
}
```

```cpp
// src/FrontendTool/IncrementalCompilerInstance.cpp

bool IncrementalCompilerInstance::PerformASTRelease()
{
    PrepareCodeGenInfo();

    if (kind == IncreKind::NO_CHANGE || kind == IncreKind::EMPTY_PKG) {
        return true;
    }

    if (!resultsSaved) {
        if (!PerformResultsSaving()) {
            return false;
        }
        resultsSaved = true;
    }

    if (ShouldWriteCacheFile() && !cacheWritten) {
        UpdateCachedInfo();
        WriteCachedInfo();
        cacheWritten = true;
    }

    if (invocation.globalOptions.noReleaseAST) {
        return true;
    }

    // Clean incremental-compilation-specific AST pointers.
    changedTypes.clear();
    declsToBeReCompiled.clear();
    cacheMangles.Clear();

    ReleaseASTMemory();
    return true;
}

bool IncrementalCompilerInstance::PerformCodeGen()
{
    if (kind == IncreKind::NO_CHANGE) {
        if (IsASTReleased()) {
            for (auto& info : codeGenPkgInfos) {
                LoadCachedCodegenResult();
                invocation.globalOptions.UpdateCachedDirName(info.fullPackageName);
            }
        } else {
            for (auto& srcPkg : GetSourcePackages()) {
                LoadCachedCodegenResult();
                invocation.globalOptions.UpdateCachedDirName(srcPkg->fullPackageName);
            }
        }
        return true;
    }

    RearrangeImportedPackageDependence();
    bool ret = true;
    if (IsASTReleased()) {
        for (auto& info : codeGenPkgInfos) {
            ret = ret && CodegenOnePackage(info.fullPackageName, info.isEmpty, kind == IncreKind::INCR);
        }
    } else {
        for (auto& srcPkg : GetSourcePackages()) {
            ret = ret && CodegenOnePackage(*srcPkg, kind == IncreKind::INCR);
        }
    }
    return ret;
}
```

## 十、安全性保证

1. **无 Use-After-Free**: 所有 AST 指针持有者在 `ReleaseASTMemory()` 中按依赖顺序清理，`astReleased` 标志防止重复释放
2. **无 Double-Free**: 析构函数通过 `if (!astReleased)` 守卫跳过已释放资源
3. **无数据丢失**: `PerformResultsSaving()` 和 `WriteCachedInfo()` 在 AST 释放前执行，返回值被检查
4. **幂等性**: 所有清理方法支持重复调用，`cacheWritten`/`resultsSaved` 标志防止重复操作
5. **向后兼容**: `--no-release-ast` 选项默认关闭，不影响现有行为
