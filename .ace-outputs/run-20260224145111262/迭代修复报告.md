# AST 内存释放 — 迭代修复报告

## 一、问题分析与根因定位

### 1. PackageCodeGenInfo 前向声明错误（编译错误）

**现象**：`CompilerInstance.h` 编译失败，`GetCodeGenPkgInfos()` 返回类型引用了未声明的 `PackageCodeGenInfo`。

**根因**：`PackageCodeGenInfo` 结构体定义在 `protected` 区域（~line 593），但 `GetCodeGenPkgInfos()` 访问器在 `public` 区域（~line 551），C++ 要求类型在使用前声明。

**修复**：将 `PackageCodeGenInfo` 结构体定义移至 `public` 区域（访问器之前），`protected` 区域仅保留 `std::vector<PackageCodeGenInfo> codeGenPkgInfos` 成员变量。

### 2. DefaultCompilerInstance CHIR 输出模式 CJO 丢失（P0 逻辑缺陷）

**现象**：当 `outputMode == CHIR` 时，CJO 文件不会被写入磁盘。

**根因**：流水线阶段顺序为 `SAVE_CJO → CHIR → RELEASE_AST → CODEGEN → SAVE_RESULTS`。在 CHIR 输出模式下：
- `PerformCjoSaving()` 跳过 CJO 保存（延迟到 `SAVE_RESULTS`）
- `RELEASE_AST` 阶段释放 `srcPkgs`
- `PerformResultsSaving()` 调用 `SaveCjo(ci.GetSourcePackages())` 时 `srcPkgs` 已被释放

**修复**：在 `PerformASTRelease()` 中，在 `ReleaseASTMemory()` 之前调用 `PerformResultsSaving()`，并用 `resultsSaved` 标志防止重复执行。这与 ADR-009 中 `WriteCachedInfo()` 的处理方式一致。

## 二、修复方案

### 修复 1：PackageCodeGenInfo 前向声明

```cpp
// CompilerInstance.h — public section (before accessor)
struct PackageCodeGenInfo {
    std::string fullPackageName;
    bool isEmpty = false;
};
const std::vector<PackageCodeGenInfo>& GetCodeGenPkgInfos() const { return codeGenPkgInfos; }

// protected section — only the member variable
std::vector<PackageCodeGenInfo> codeGenPkgInfos;
```

### 修复 2：PerformASTRelease 中提前保存结果

```cpp
bool CompilerInstance::PerformASTRelease()
{
    PrepareCodeGenInfo();

    // P0 fix: Save results before AST is freed.
    if (!resultsSaved) {
        PerformResultsSaving();
        resultsSaved = true;
    }

    // ADR-009: Write cache before AST is freed.
    if (ShouldWriteCacheFile() && !cacheWritten) {
        UpdateCachedInfo();
        WriteCachedInfo();
        cacheWritten = true;
    }

    if (invocation.globalOptions.noReleaseAST) {
        return true;
    }

    ReleaseASTMemory();
    return true;
}
```
