# PR & Issue compliance pipeline experiment

This temporary documentation-only change is used to verify the
`check_pr_issue_compliance.py` pipeline integration.

The experiment checks that:

- a pull request and its linked issue are collected correctly;
- repository pull-request and issue templates are supplied to the model;
- the `ai check` comment triggers the pipeline; and
- the generated compliance result is posted back to the pull request.

This file contains no product or compiler behavior changes and can be removed
when the experiment is complete.
